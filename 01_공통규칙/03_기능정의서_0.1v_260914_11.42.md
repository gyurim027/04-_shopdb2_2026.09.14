# 기능 정의서

- 버전: 0.1v (초안)
- 작성일시: 2026-09-14 11:42
- 참고 문서: [01_테이블정의서](./01_테이블정의서_0.1v_260914_11.42.md), [02_사용자구조및서비스방향성](./02_사용자구조및서비스방향성_0.1v_260914_11.42.md)

문서 2에서 어드민/대고객 방향성이 아직 A/B 중 확정되지 않았으므로, 이 문서는 **양쪽 방향 모두에서 필요한 기능을 도메인별로 전부 나열**합니다. 각 기능에는 대상 화면, 근거 테이블, 그리고 특정 방향성에서만 필요한 경우 비고를 표시했습니다. 우선순위 선택 후 이 목록에서 1차 범위를 추립니다.

표기: 화면 축 = **어드민** / **대고객** / **셀러**(방향성 문서 4장 참고, 확장 후보)

## 우선순위 제안 (참고용, 확정 아님)

문서 2의 방향 선택에 따라 아래와 같이 단계적 구축을 제안합니다. 최종 선택은 사용자가 진행합니다.

1. **1단계 (필수 기반)**: 1장(사용자/조직) + 2장(상품/재고) + 3장(주문/결제) — 어느 방향을 택하든 공통으로 필요
2. **2단계**: 4장(환불) + 6장(문의/정책) — 표준 CS 기능
3. **3단계 (방향 선택에 따라 분기)**: 어드민 방향 A 선택 시 조직별 권한 세분화 강화 / 대고객 방향 A 선택 시 7장(AI/RAG) 착수
4. **확장 후보**: 5장 파일 기능 고도화, 셀러 콘솔 별도 구축
