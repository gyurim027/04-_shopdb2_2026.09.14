# Category Menu Rework - 2026-09-17

이번 버전은 메인 화면 왼쪽에 카테고리 목록을 항상 노출하던 구조를 제거하고,
일반 종합 쇼핑몰처럼 헤더의 `카테고리` 버튼에 마우스를 올렸을 때만 메뉴가 열리도록 변경했다.

## 동작

1. 평소에는 카테고리 목록이 보이지 않는다.
2. 헤더 왼쪽 파란 `카테고리` 버튼에 마우스를 올리면 1차 카테고리 메뉴가 열린다.
3. 1차 카테고리는 비슷한 상품군을 묶어 15개로 정리했다.
4. 1차 카테고리에 마우스를 올리면 오른쪽에 해당 세부 카테고리가 표시된다.
5. 메뉴는 배너 위에 overlay로 표시되므로 홈 화면 레이아웃을 밀어내지 않는다.
6. 모바일/태블릿에서는 hover 대신 카테고리 버튼 클릭으로 열고 닫을 수 있다.

## 15개 1차 카테고리

- 패션의류/잡화
- 뷰티
- 출산/유아동
- 식품
- 주방용품
- 생활용품
- 홈인테리어
- 가전디지털
- 컴퓨터/모바일
- 스포츠/레저
- 자동차용품
- 도서/문구/오피스
- 완구/취미
- 반려동물용품
- 헬스/건강식품

## 추가 변경

- 홈 화면의 고정 카테고리 사이드바 제거
- 홈 배너를 전체 콘텐츠 폭으로 확장
- 상품 목록 페이지의 카테고리 필터도 동일한 15개 그룹으로 통일
- 그룹을 선택하면 상단에 세부 카테고리 버튼 표시
- 기존 로그인/BUTER 권한/주문/결제/환불/문의/AI API 구조는 변경하지 않음
- Backend/DB schema 변경 없음
