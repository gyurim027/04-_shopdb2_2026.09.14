# Customer Frontend Commerce UI Reinforcement — 2026-09-17

## 보강 기능
- 상품 목록 정렬: 추천순 / 낮은 가격순 / 높은 가격순 / 할인율순 / 상품명순
- 검색·카테고리·정렬 필터 상태 표시 및 전체 초기화
- 숫자형 페이지네이션
- 상품 이미지 로딩 실패 fallback
- 상품 카드 품절/할인/재고 표시
- 상품 목록/상세 Skeleton UI
- 상품 상세 이미지 갤러리, 할인율, 재고 표시, sticky 구매 패널
- 주문내역 상태 필터 및 주문번호 검색
- 주문상세 4단계 진행 표시
- 환불 사유 선택 + 상세 사유 + 접수 전 확인
- 고객센터 문의 상태/카테고리/제목 필터
- AI 도움말은 메인에서 강조하지 않고 보조 기능으로 유지

## 디자인 개선
- 대형 종합 쇼핑몰을 참고한 상단 유틸리티 바 / 카테고리 버튼 / 대형 검색창 구조
- 마이페이지·주문목록을 헤더 핵심 액션으로 배치
- 메인 좌측 카테고리 메뉴 + 우측 상품 프로모션 배너
- 메인 섹션을 `오늘의 발견`, `오늘의 쇼핑 제안`, `할인 상품` 중심으로 재구성
- `신상품/NEW` 섹션 및 최신등록순 정렬 제거
- 상품 카드를 둥근 카드형보다 실제 종합 쇼핑몰에 가까운 평면형 목록 스타일로 변경
- 5열 상품 그리드와 모바일 2열 반응형 적용
- 과도한 그라데이션, Sparkles, AI 중심 카피 제거
- 푸터를 일반 쇼핑몰형 링크/고객지원 구조로 변경

## 유지한 정책
- 장바구니 미구현: 기존 바로구매 흐름 유지
- 기존 FastAPI API 경로 유지
- BUYER 권한 및 로그인 보호 로직 유지
- DB/백엔드 스키마 변경 없음
