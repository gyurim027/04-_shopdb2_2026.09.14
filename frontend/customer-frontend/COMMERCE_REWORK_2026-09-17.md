# Customer Frontend Commerce Rework — 2026-09-17

## 목표
기존의 둥근 카드/그라데이션/영문 키커/AI 중심 표현을 줄이고, 국내 대형 종합 쇼핑몰에서 익숙한 정보 밀도와 쇼핑 동선을 참고해 Customer 화면을 재구성했습니다.

## 핵심 변경
- `신상품/NEW` 영역 완전 제거
- `최신 등록순` 정렬 제거
- 상단 유틸리티 바 + 카테고리 버튼 + 대형 검색창 + 마이페이지/주문목록 구조
- 메인 좌측 카테고리 메뉴 + 우측 프로모션 배너
- 빠른 이동: 전체상품 / 할인상품 / 주문조회 / 취소·환불 / 고객센터 / 이용정책
- 홈 상품 영역: 오늘의 발견 / 오늘의 쇼핑 제안 / 할인 상품
- 상품 카드: 둥근 카드와 큰 배지 대신 평면형 상품 리스트 스타일
- 데스크톱 5열, 모바일 2열 상품 그리드
- AI 기능은 헤더의 보조 링크로 축소
- 개발자용 문구(`Mock 결제`, 백엔드 정책 설명)를 고객 화면에서 제거
- 쇼핑몰형 푸터로 단순화

## 유지 사항
- 기존 Customer API 경로
- BUYER 인증/보호 라우트
- 배송지/주문/결제/환불/문의/AI 기능
- 장바구니 없이 바로구매 흐름
- DB와 백엔드 수정 없음
