# 카테고리 버튼 / 검색 카테고리 보강

## 변경 사항

- 데스크톱 카테고리 버튼 높이를 메인 헤더 높이(94px)에 맞춤
- 기존처럼 하단 빠른 메뉴 줄까지 파란 버튼이 내려오지 않도록 수정
- 카테고리 hover 메뉴는 카테고리 버튼 바로 아래에서 열리도록 위치 조정
- 상단 검색창의 `전체` 선택란에 15개 묶음 카테고리를 추가
- 검색 카테고리를 선택하고 검색하면 `/products?group=...&keyword=...` 형식으로 이동
- 검색어가 없어도 카테고리를 선택한 뒤 검색 버튼을 누르면 해당 카테고리 상품 목록으로 이동
- 상품 목록 페이지의 기존 group/sub 필터와 그대로 연동
